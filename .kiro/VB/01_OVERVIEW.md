# APLIKASI PENJUALAN - ANALISIS LENGKAP

## 1. OVERVIEW APLIKASI

### Nama Aplikasi
**MINTAN / ITSERVICE - Aplikasi Penjualan & Distribusi LPG**

### Teknologi Stack
- **Platform**: Desktop Application (Windows Forms)
- **Language**: Visual Basic .NET (VB.NET)
- **Framework**: .NET Framework
- **UI Framework**: MetroFramework (Modern UI)
- **Database**: Microsoft SQL Server
- **Reporting**: Crystal Reports & Microsoft ReportViewer
- **Connection**: ADO.NET (SqlClient)

### Tujuan Bisnis
Aplikasi ini digunakan untuk mengelola:
1. **Transaksi Pembelian** (Beli) - Pembelian LPG dari supplier
2. **Transaksi Penjualan** (Jual) - Penjualan LPG ke customer/pangkalan
3. **Master Data** - Customer, Supplier, Driver, Mobil, Barang
4. **Akuntansi** - COA, Kas, Jurnal, Laba Rugi, Neraca
5. **Laporan** - Faktur, Invoice, Laporan Keuangan

### Multi-Company Support
Aplikasi mendukung multiple PT (Perusahaan):
- **KIDUNG** (Agen Kidung)
- **MINTAN SAMUDRA** (Agen Mintan Samudra)
- **MINTAN GASINDO** (Agen Mintan Gasindo)
- **MIGASTRACO** (Agen Migastraco)
- **SUDI MULYO** (diganti Mintan Regar)
